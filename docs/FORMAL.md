# 形式化保证（Formal guarantees）

> 引用说明：文中的 `R2_RESULTS §x` 指 ProvenMark 实验报告的章节（对外以白皮书形式发布）；"机器检验"一栏列出的测试位于 ProvenMark 主仓库，
> 公开的复核工具仓库包含 SMT 证明脚本 `formal/smt_proofs.py` 及其测试。

本文件把 ProvenMark 能**严格证明**的性质写成命题与证明，并逐条说明它们依赖的假设、在哪里被机器检验、以及哪些性质
**无法**形式化证明、只能用实验给出。对外宣称时，只能引用"已证明"一栏的结论，并连同假设一起引用。

## 记号与假设

* 密钥 K；伪随机函数 F_K（AES-256 计数模式，`prf.py`）。符号序列 w(a) = sign(F_K(域, a)) ∈ {−1, +1}。
* **A1（伪随机性）**：对不知道 K 的任何高效算法，{w(a)} 与独立、等概率的 ±1 序列不可区分。这是 AES 的标准假设。
  下面的统计结论在"w 是真正独立等概率 ±1"的理想模型下证明；A1 保证现实中的偏差可忽略。
* **A2（零假设下的独立性）**：H0 = "可疑数据与这把密钥无关"（未标记、或用别的密钥标记）。则可疑数据 x 与 w 独立。
* **A3（训练与划分无关）**：H0 = "嫌疑模型没有在交付给接收方 r 的数据上训练"。则模型的逐块损失 ℓ 与 r 的留出划分 W_r 独立。

## P1 保真约束

**命题。** 设原始数据 X 满足：被检查的值都在量程内的仍记为"在内"；`enforce(X, X + D₀, C)` 返回 X + D。则对任意 D₀：
(i) |D_ij| ≤ tol_j；(ii) 若 X_ij ∈ [lo_j, hi_j]，则 X_ij + D_ij ∈ [lo_j, hi_j]；
(iii) 对每条线性守恒律 a，D a = 0；(iv) 对每个声明变化率 r_j 的通道，若原始步长 |ΔX| ≤ r_j，则新步长 |Δ(X + D)| ≤ r_j。
（量化步长若声明，最后执行，不在本命题内；故障标签列不被修改。）

**证明。** 先把 D₀ 投影到守恒律的零空间：D ← D₀ Pᵀ，P = I − Aᵀ(AAᵀ)⁺A，所以 D A ᵀ = 0。之后只做**整行缩放** D_i ← s_i D_i，s_i ∈ [0, 1]，
缩放保持 D Aᵀ = 0，得 (iii)。每一轮对每行取满足 (i)、(ii) 的最大 s_i：(i) 取 s_i ≤ tol_j / |D_ij|；(ii) 因区间是凸的、X_ij 在区间内，
X_ij + s D_ij 对 s ∈ [0, s*] 都在区间内。缩放只会让 |D_ij| 变小，所以 (i)、(ii) 一旦成立就保持。对 (iv)，违反步长的两端整行置零。
循环直到某一轮所有 s_i = 1（不动点）。**终止性**：非最后一轮至少把一行严格缩小或置零；置零的行不会再变，而变化率检查只会把行置零，
所以变化率导致的轮次至多 n 次；当所有行为零时 D = 0，各检查对原始数据成立（(iv) 只检查原始步长 ≤ r_j 的位置）。
不动点处所有检查通过。∎

## P2 不变性

**命题。** 对 a > 0、任意 b 和任意行排列 π，`ssw.detect` 与 `csw.detect` 的 z 不变。

**证明。** 检测按每行的地址（时间戳或 ID）排序，所以行排列不改变输入。高通残差 r = x − 邻域均值（`ssw`：逐点；`csw`：每个码片的均值减去相邻码片均值）
是线性的、且对常数为零，所以 x → a x + b 时 r → a r；截尾阈值是稳健尺度的倍数，同样乘 a。z = Σ r_i w_i / √Σ r_i² 关于 a > 0 是零次齐次的。∎

## P3、P4（留出分配与置换 p 值）

P3：`assign` 用 F_K 对块编号排序，取前 k = max(1, round(q n)) 个，确定且恰好 k 个。∎
P4：p = (1 + #{j : S_j ≥ S₀}) / (1 + m)，分子在 [1, 1 + m]，故 p ∈ [1/(1+m), 1]；所有损失加同一常数时，两组均值之差不变，S 不变。∎

## T1 拷贝检测的误报率

**定理。** 在 A1、A2 下，对固定的可疑数据 x，令 r 为其（截尾后的）高通残差，T = Σᵢ rᵢ wᵢ / √Σᵢ rᵢ²（`csw` 中 i 为码片）。则
E[T | x] = 0，Var[T | x] = 1，并且 P(T ≥ t | x) ≤ exp(−t²/2)（Hoeffding）。因此任何数据——无论自相关多强、分布如何——误报率都不超过
exp(−t²/2)；当残差没有被少数项主导时，由 Lindeberg 中心极限定理，T 近似 N(0, 1)。

**证明。** 给定 x，r 是常向量；wᵢ 独立、等概率 ±1，且（A2）与 r 独立。E[rᵢ wᵢ] = 0，Var[Σ rᵢ wᵢ] = Σ rᵢ²。
Hoeffding 不等式对有界独立项 rᵢ wᵢ ∈ [−|rᵢ|, |rᵢ|] 给出 P(Σ rᵢ wᵢ ≥ t √Σ rᵢ²) ≤ exp(−2 t² Σ rᵢ² / Σ (2 rᵢ)²) = exp(−t²/2)。∎

**要点。** 数据的自相关只进入 r，而结论对任意 r 成立；这就是"不需要校准"的含义。截尾（winsorize）只是限制单项占比，使正态近似更好；
Hoeffding 界与截尾无关。多个文件 / 列的 Stouffer 合并：各项独立（不同列、不同文件用的符号互相独立）时，同样的论证给出合并后的界。
带偏移搜索时取 2S+1 个偏移的最大值，用 Bonferroni 乘 2S+1，由联合界保持有效（T4）。
**注意**：p 值报告用正态尾概率；在证据场合可以改用更保守的 Hoeffding 界 exp(−z²/2)。
**适用范围**：T1 只覆盖 `ssw` 与 `csw`；`evt` 的匹配数在 A1、A2 下是精确的 Binomial(N, 1/2)，同理有效。
`tone` **不在** T1 范围内，见下面的 N1。

## T2 留出验证集的置换检验

**定理。** 设所有者用接收方 r 的真实密钥 K₀ 与 m 把诱饵密钥 K₁..K_m（由公开种子确定、与 K₀ 独立地生成）计算统计量 S_j = S(ℓ, W_{K_j})。
在 A1、A3 下，(W_{K₀}, W_{K₁}, …, W_{K_m}) 与 ℓ 独立且是可交换的（独立同分布的随机划分），因而 S₀, …, S_m 可交换，
p = (1 + #{j ≥ 1 : S_j ≥ S₀}) / (1 + m) 满足 P(p ≤ α) ≤ α 对所有 α ∈ [0, 1] 成立。

**证明。** 可交换性下，S₀ 在 S₀..S_m 中的秩在 {1..m+1} 上均匀（并列时取保守方向）。p ≤ α 等价于 S₀ 至多被 ⌊α(1+m)⌋ − 1 个诱饵超过，
其概率 ≤ ⌊α(1+m)⌋ / (1+m) ≤ α。∎

**参考模型归一化**：用 log(ℓ_b / ref_b) 代替 ℓ_b。只要参考模型的损失 ref 不依赖任何接收方的划分（它在全部块上训练，或是确定性的岭回归），
归一化后的 ℓ' 仍与划分独立，定理不变。参考模型若"偏向"留出块（所有者作弊的唯一途径），会被公平性检验检出；
仲裁方按签名登记的配方自己训练参考模型，排除这种作弊。

**假设何时会被破坏**（必须随结论一起声明）：
* 嫌疑模型的训练数据**合法地**包含原始数据的一部分（第三方独立持有同一来源的数据）：A3 不成立。SKAB 上发现过这种情况（R2_RESULTS §2.14）。
* 留出划分泄露给了被许可方以外的人，或交付文件之外的渠道泄露了留出块。

## T3 条件归因

**定理。** 设真正的泄露方是 o（模型只在交付给 o 的块 D_o = ¬W_o 上训练，加上与所有划分无关的外部数据），r ≠ o 是无辜接收方。
条件检验只用 D_o 中的块计算 S(ℓ|_{D_o}, W_r ∩ D_o) 与诱饵的同一统计量。则在 A1 下，对 r 的条件 p 值有效：P(p_{r|o} ≤ α) ≤ α。

**证明。** 给定 W_o，模型在 D_o 中的每一块上都训练过，训练过程与 W_r 无关（W_r 由独立密钥生成）。所以给定 W_o，ℓ|_{D_o} 与 W_r ∩ D_o 独立，
诱饵划分限制到 D_o 后与 W_r ∩ D_o 同分布且可交换；套用 T2。∎

**为什么边际检验不够**：边际检验中 ℓ 依赖 W_o，而 W_r 与 W_o 的重叠是随机的；与 W_o 重叠多的 W_r 会继承信号。
T2 对单个无辜方仍然成立（它的划分与 W_o 独立，平均意义上可交换），但在"给定泄露方"条件下不成立——SKAB 与模拟都观察到了这一点。
**归因规则**：r 被指认，当且仅当边际 p 与"以其他最强的 c 个接收方为条件"的 p 都 ≤ α / N。若真正的泄露方 o 在这 c 个之中，无辜方的条件检验有效，
族错误率 ≤ α（T4）；若 o 不在其中（o 的信号太弱），保证退化为边际检验的保证。

## T4 多重检验

Bonferroni（k 个检验取最小 p 再乘 k）对任意依赖结构有效（联合界）。Fisher 合并要求各 p 值独立且有效（super-uniform 时保守）。
**因此判定用的 Fisher 合并只纳入 p 值有效的方法**（`ssw`、`csw`、`evt` 等）；`tone` 只列出、不计入（N1，`core.INFO_ONLY_METHODS`）。
把一个无效的 p 值放进 Fisher，整个合并 p 值随之失效——这正是 N1 导致错误指认的路径。
"best-of-two 参考"= 两个有效 p 取小再乘 2，是 Bonferroni 的特例。接收方筛查乘以接收方数 N，同样是 Bonferroni。

## N1 `tone` 的 p 值不是有效的检验（更正，2026-11）

**原先的说法**：`tone` 用参数化近似 p = (1 + r/N)^−N（r = 目标频率处功率与 N 个参考频率平均功率之比），
"在 AR / 随机游走噪声上检查过是保守的"（THREAT_MODEL）。**这只在目标频率附近是连续谱噪声时成立。**

**反例（实测）**：在演示数据（振动通道含一条自身的周期成分）上，用 2,000 把无辜密钥检测一份泄露拷贝，
P(p ≤ 0.05) = 6.4%，P(p ≤ 1e-3) = 3.7%，**P(p ≤ 1e-6) = 2.4%**，最小 p = 1.6e-80。原因：嵌入时只检查了**真密钥**的频率在原始数据上是否"安静"；
无辜密钥（或与数据无关时的任意密钥）的频率按密钥随机落在频带内，落到数据自身谱线的主瓣内时，比值 r 极大，p 极小，而这与密钥无关。
数据含谱线时，P(p ≤ α) 至少约为"谱线主瓣覆盖的频带比例"，与 α 无关，所以对小 α 远超名义水平。
在泄露追溯中这导致了错误指认：与 `tests/test_evidence.py` 相同的场景下，`ssw` + `tone` 用 Fisher 合并时 150 次中 7 次（4.7%）
在 α = 1e-6 下额外指认了一个无辜接收方；只用 `ssw` 时 0/150。工业数据（旋转设备、电网频率、控制回路振荡）普遍含谱线，所以这不是边缘情况。

**处理（2026-11）**：`tone` 的 p 值只作参考列出，不进入 Fisher 合并、`detect` / `trace` 的判定和证据包的结论；CLI 默认方法改为 `ssw,csw`。
`tone` 作为训练探针时用的是诱饵密钥置换检验（`audit` / `probe`），不受此影响，但那里的可交换性同样要求诱饵频率与真频率按同一规则产生。
**若要恢复 `tone` 的判定地位**，需要换成在 H0 下有效的检验（例如诱饵密钥置换，诱饵频率按与真密钥相同的选取规则生成），并重新做零分布校准。

## S1 密钥不可逆向（"用 AI 破解水印"）

**归约。** 标记中所有依赖密钥的量——每个采样点 / 码片的符号、`csw` 的码片长度与相位、留出划分、诱饵之外的一切——都是 F_K 在公开输入上的输出。
若某个算法（包括任何机器学习模型）仅凭标记数据就能以不可忽略的优势预测未见位置的符号，或恢复 K，它就构成了区分 AES 与随机置换的区分器，
与 A1 矛盾。因此"让 AI 学会密钥 / 预测水印序列"在 A1 下不可行。

**这不覆盖的攻击**（只能实验评估，E1）：
* **不需要知道密钥的去除**：低通 / 去噪 / AI 去噪器把所有不可预测的细节一起抹掉。它不恢复密钥，但可能抹掉标记，代价是数据失真。
  `csw` 的密钥化码片网格（长度、相位按密钥逐超块变化）用来对抗"知道算法、猜网格"的定向去除。
* **多份拷贝合谋**：比较不同接收方的拷贝可以定位差异位置。2–3 方平均仍可指认，≥5 方加噪会失效（需要抗合谋编码）。
* **检测预言机**：若攻击者能反复调用检测器，可以逐步试探。ProvenMark 的检测需要密钥、不公开提供；证据包只披露已作废的子密钥。

## 不能形式化证明的部分（E1、E2）

* **稳健性**：对攻击的稳健性取决于攻击者愿意付出的失真，以及我们没有想到的攻击。只能给出"在这些攻击、这些参数下"的实验结果（R2_RESULTS §2.15）。
* **训练使用的检出力**：模型会不会记住交付数据，取决于架构、训练量、正则化与规避手段；线性模型通常不记，弱记忆模型在有意规避下检不出。
  T2/T3 只保证"检出时可信"（误报受控），不保证"使用了就能检出"。

## 机器证明（`formal/smt_proofs.py`，z3）

每条引理都对**所有实数输入**成立，z3 通过证明其否定不可满足来证明它；运行 `python formal/smt_proofs.py`（测试 `test_formal_smt.py`）。
脚本先做非空性检查：故意写错的变体必须被 z3 找到反例，否则说明设定本身有问题。

| 引理 | 内容 | 范围 |
|---|---|---|
| L1 | 秩引理：任意 m+1 个实数中，p_i = (1 + #{j≠i: s_j ≥ s_i})/(1+m) ≤ k/(1+m) 的下标至多 k 个——置换 p 值有效性（T2）的组合核心 | m = 1…7、所有 k（35 个实例） |
| L2 | 守恒律 a = (1, 1, −1)：零空间投影后再任意整行缩放，D·a = 0（P1-iii） | 任意 D、任意缩放 |
| L3 | 缩放 s = min(1, tol/|d|) 后 |s d| ≤ tol 且 s ∈ [0, 1]（P1-i） | 完全一般 |
| L4 | 量程的凸性：x 与 x + s*d 都在 [lo, hi] 内，则所有更小的 s 也在内（P1-ii） | 完全一般 |
| L5 | 掩码统计量与掩码外的块无关（条件归因 T3 的前提） | 6 个块、任意分配与掩码 |

**仍未机器证明的部分**：T1 的 Hoeffding 界与 T2 从秩引理到"p 值 super-uniform"的概率论一步（需要 Lean 4 + Mathlib 的测度论；
本环境的安全策略不允许运行外部安装脚本，需要所有者授权安装 Lean 工具链）；以及实现代码与引理之间的对应——
由 `tests/test_properties.py` 的性质测试和每次发布的运行时证书来衔接。
